# Usage & Tests

This document explains how to set up the environment, run the Toy example, generate mock data and run tests.

Setup

1. Create and activate a Python virtual environment

```bash
python3 -m venv .venv
source .venv/bin/activate
```

2. Install dependencies

```bash
pip install -r requirements.txt
```

Generate mock data (Toy)

```bash
python tools/mock_generator.py --out patterns/Toy_Example/sample.csv --n 50
```

Run the Toy analysis (ETL -> metrics -> reports -> explainer -> frontend payload)

```bash
python patterns/Toy_Example/analysis.py --input patterns/Toy_Example/sample.csv --outdir patterns/Toy_Example/out
```

Programmatic example (importable)

```python
from archspaces.example_archspace import run_toy_example
run_toy_example("patterns/Toy_Example/sample.csv", "patterns/Toy_Example/out")
```

Run tests

```bash
pytest -q
```

Notes

- The Toy pipeline uses a lightweight pandas ETL at `patterns/Toy_Example/etl.py`.
- Explanations are generated by `archspaces/llm_explainers.py` using a local template.
- Frontend payloads are written to `frontend_payload.json` and contain a compact `metrics` summary and `charts` list.
