# Technology Stack: patterns-sa

## Core Programming Language
- **Python (3.x):** The primary language for all analysis logic, data processing, and CLI tools.

## Data Analysis & Scientific Computing
- **Pandas:** Used for structured data manipulation and analysis of simulation results (CSV/DataFrames).
- **NumPy & SciPy:** Foundational libraries for numerical computing and statistical analysis.
- **Pydantic:** Used for strict data validation and schema management of architectural pattern definitions.

## Architectural Analysis & Discovery
- **EMA Workbench:** A key framework for performing Exploratory Modeling and Analysis, including scenario discovery.
- **PRIM & CART:** Specific algorithms used for scenario discovery and identifying the "boxes" of architectural success/failure.
- **Scikit-Learn:** Utilized for various machine learning and statistical modeling tasks.

## Visualization & Reporting
- **Matplotlib & Seaborn:** The standard libraries for generating static, publication-quality scientific charts.
- **Graphviz & Pydot:** Used for generating and manipulating graph-based architectural representations.
- **Pyvis, Gravis, & Dtreeviz:** Libraries for interactive graph visualizations and specialized decision tree visualizations.

## Development & Testing
- **Pytest:** The primary testing framework for unit and integration tests.
- **JSON:** Used as the primary format for externalizing architectural pattern definitions and configurations.
