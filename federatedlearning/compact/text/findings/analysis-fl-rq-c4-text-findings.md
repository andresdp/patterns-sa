## RQ1 — Which tradeoffs occur, and how do design choices relate to them?

L-M is largest (184/273 train, 79/117 test), followed by L-S (69/273, 31/117). No complete configuration is deterministic; pattern marginal exclusivity is mixed (e.g. M-S/L-L attributed to some ON/OFF marginals), so it is not an isolated pattern effect. The all-configuration sample represents multiple policies at one client count; context mixes sampled delay, non-IID, and resource conditions. All 0/1/2/3 active-type groups occur (60/170/130/30 runs); aggregate means differ, but groups mix complete configurations. Pattern Instances vary 0–7 and represent run context/stress, not assigned policy. Compare configurations only within the stated client scope; `Pattern Types Active` counts decisions, whereas `Pattern Instances` is a context-dependent deployment/stress descriptor. The accuracy–time plot corroborates occupancy: [quality-space plot](../plots/quality-space__task-text__all-configurations__clients-4__environment-all__final_val_accuracy-vs-avg_total_time.png). Notebook contingency and robustness outputs: [analysis notebook](../analysis-fl-rq-c4-text.ipynb) (Sections 5–7; cells 30–44).

## RQ2 — Which joint conditions identify a target tradeoff, and what changes inside the box?

Importance is training-slice predictive credit, not effect direction. Rank order is model-specific; pattern settings with constant values and correlated proxies receive zeroed or omitted credit. Training feature ranking emphasizes Alpha Dirichlet Mean, delay percentage, Client Selector Criteria, HDH Instances and CPU Mean (relative model credit). PRIM/CART agree on a high-accuracy/short-time L-S rule requiring Client Selector ON (CPU criterion) and delay ≤12.5%; held-out precision is 100% (6/6), but coverage is 6/31 (19.4%). L-M has 100% precision at 45/45 retained and captures 45/79 targets (57.0%), associated with delay ≥12.5%, low pattern/HDH instance counts and Client Selector not-selected/OFF. M-S box evaluation is sparse (1 target hit of 8 retained, baseline 2/117; coverage 50%); M-M has a discovered box but zero held-out target rows, hence no test precision/recall validation. L-L is supported by only 5 test targets; PRIM retains 5/12 (precision 41.7%, full target coverage), CART retains 3/3 (100% precision, 3/5 coverage). PRIM L-M includes Client Selector Criteria = not selected, consistent with Client Selector OFF in retained rows; this is a box state, not a causal requirement. For target coverage and held-out policy matrices, see notebook Section 11 (cells 66–73) and [box report](../boxes/boxes__task-text__all-configurations__clients-4__environment-all.md). The feature ranking plot is [feature-importance plot](../plots/feature-importance__task-text__all-configurations__clients-4__environment-all.png). A box is a joint observational rule, and filtering is a what-if over already observed held-out rows.

## Implications

- **Practitioners:** Treat the reported rule as a candidate monitoring/selection envelope within this exact task and configuration/client scope. Validate on additional seeds before operational use; sparse targets and retained subsets limit confidence.
- **Researchers:** The fixed-grid occupancy and grouped seed holdout support descriptive within-slice comparisons. Policy attribution is limited by observational coverage, uneven environment composition, run-level aggregates, and rare/empty regions. Importance ranks are model-relative predictive credit, not slopes or causal effects.

## Case limitations and evidence

The compact client/resource/non-IID summaries aggregate at run level and hide client- and round-level variation. Empty grid cells mean unobserved in this sample, not infeasible. All conclusions are conditional on the sampled environments and seeds.
